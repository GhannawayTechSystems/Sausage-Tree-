# Sausage Tree Lodge Website

Static responsive HTML/CSS/JS hotel/lodge website.

## Pages
- index.html
- about.html
- accommodation.html
- gallery.html
- experiences.html
- dining.html
- contact.html

## Images
Images are grouped by section in:
assets/images/hero
assets/images/about
assets/images/accommodation
assets/images/gallery
assets/images/experiences
assets/images/dining
assets/images/contact

The included SVGs are clearly marked placeholders. Replace them with the lodge's actual JPG/WEBP photos and update the paths if needed.

## Run
Open index.html in a browser, or upload the whole folder to cPanel/public_html.

## Next step
The booking form currently displays a confirmation in JavaScript. It can be connected to PHP/MySQL, email, WhatsApp or an online booking engine.
